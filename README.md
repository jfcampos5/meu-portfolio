## 🚀 Sobre o projeto

Este projeto nasceu para apresentar meu trabalho de forma clara e profissional. Foi construído do zero, sem frameworks, para praticar os fundamentos do desenvolvimento web: HTML semântico, CSS responsivo e JavaScript.

## 🛠️ Tecnologias utilizadas

- **HTML5**: estrutura semântica (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3**: Flexbox, Grid, variáveis de cor e design responsivo
- **JavaScript**: animações de entrada com `IntersectionObserver`
- **Git e GitHub**: versionamento do código
- **Vercel**: deploy e publicação contínua

## 📱 Funcionalidades

- Layout responsivo para celular, tablet e computador
- Animações suaves de entrada ao rolar a página
- Menu de navegação com links para cada seção
- Cards de projetos com links para o site online e para o código
- Etiquetas de tecnologia em cada projeto

## ♿ Acessibilidade e boas práticas

- Link "Pular para o conteúdo" para navegação pelo teclado
- Foco visível em links e botões
- `aria-label` nos links dos projetos, para leitores de tela
- Respeito à preferência de redução de movimento (`prefers-reduced-motion`)
- Meta description e tags Open Graph para SEO e prévia ao compartilhar o link
- Links externos com `rel="noopener noreferrer"`

## ▶️ Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/jfcampos5/meu-portfolio.git
   ```
2. Entre na pasta:
   ```bash
   cd meu-portfolio
   ```
3. Abra o arquivo `index.html` no navegador.

Não é preciso instalar nada: o projeto usa apenas HTML, CSS e JavaScript puros.
